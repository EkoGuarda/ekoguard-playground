# ekoguard-playground

The place for some test cases and experimental implementations.

## Overview

This repository contains various test cases, experiments, and example implementations for exploring different concepts and algorithms.

## Examples

### Monte Carlo Method - Pi Calculation

See [`examples/monte-rust/`](examples/monte-rust/) for a Rust implementation demonstrating how to calculate Pi using the Monte Carlo method. This example uses random sampling to estimate the value of π by simulating random points in a unit square and determining the ratio that fall within a quarter circle.
